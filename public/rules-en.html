How to play Picas y Fijas

Picas y Fijas is a two-player deduction game, known in English as Bulls and Cows and closely related to Mastermind. Each player hides a secret code and the first to crack their opponent's code wins. It is free and runs in the browser, with nothing to install.

The basics

Your opponent hides a code. You propose codes and every try comes back with a clue. Whoever cracks the other’s code first wins.

Fija (F)“Fixed”: in the code and in the right spot.
Pica (P)“Present”: in the code, but in another spot.
NothingNot in the code.

An example

Secret code4271
Your try4793

1 fija 1 pica

  • The 4 is in the right spot: a fija.
  • The 7 is in the code, but in another spot: a pica.
  • The 9 and the 3 are not in the code.

In a game you only see the totals — “1 fija, 1 pica” — never which digit earned which clue. That is where the deduction begins.

Color codes work the same way: colored pegs instead of digits, and every color also has its own shape.

The duel

The classic game: two people, two secret codes and one try per turn.

  1. Create the gamePick the rules and your secret code. You get a 4-character game code and a link to invite someone.
  2. Your opponent joinsFrom the lobby, with the code or with the link, and sets their own secret under the same rules. The first turn is drawn at random.
  3. Take turns guessingEvery try gets its fijas and picas. You can go back to the lobby whenever you like: the game stays open.
  4. First to crack the code winsIf the player who opened the round cracks it, the other gets one last try to tie. With an attempt limit, if nobody cracks it, it is a draw.

More modes

There is not always an opponent free. That is what these four are for.

The arena

3 to 8 players One code No turns 6 or 10 tries

The server draws the code and everyone attacks it at once. You see the live standings — tries used and best number of fijas for each player — but never anyone else’s tries. Whoever cracks it in the fewest tries wins. The host starts it, with at least 3 players.

No season points. Winning it earns the “First arena” badge.

Code of the day

4 digits, no repeats 8 tries Once a day

The same code for everyone. It changes at midnight UTC. The day’s standings rank by tries and then by time. When you finish you can share your grid without revealing the code.

No season points.

Puzzles

72 puzzles 3 levels No clock

We give you the clues from a game you did not play: deduce the only code that fits. With an account, what you solve follows you to any device, and completing a level earns a badge.

Playable without an account too.

Practice

Solo Against the computer Offline

The same rules as a duel, with nobody to wait for. The computer has three levels — easy, normal and expert — and explains every move it makes.

No account needed, no effect on the ranking.

And more

Good to know before your first game.

Do I need an account?
To play against other people, yes: an email, a name and a 4-to-8-digit PIN. The account is activated by opening the link we email you, valid for 3 days. Without an account you can practice and solve puzzles. If you forget your PIN, an emailed link resets it.
What happens if I leave a game?
Going back to the lobby neither deletes nor abandons it: it stays among your games. Abandoning does end it: your opponent wins and you get 0 points. Whoever created a game can cancel it while it is still waiting for an opponent, at no cost.
How long does a game wait?
A public game waits 2 hours for an opponent; a private invitation, 48 hours. A game in progress closes after 48 hours without activity, except correspondence games, which follow their own deadline.
How do I talk to my opponent?
There is a general chat in the lobby and a private chat in every game. The nudge tells your opponent it is their turn, and the quick reactions — Good luck!, So close!, Nice move!, Good game! — take a single tap.
Can I watch other people’s games?
Yes: from the lobby, any public game in progress. You see the tries, the clues and the clock live; never a code, not even at the end. The game chat can be read, not written to.
Will it tell me when it is my turn?
With the game open, with sound and vibration. With the game closed, through notifications if you turn them on; on iPhone they only arrive once the game is installed on your home screen. How to install it
